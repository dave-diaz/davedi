Physical and virtual appliances

Device Definition
RouterForwards packets between networks using IP routing.
SwitchConnects devices within a LAN and forwards frames by MAC.
FirewallEnforces security policies by filtering and blocking traffic.
IDS/IPSDetects (IDS) and prevents (IPS) malicious network activity.
Load balancerDistributes incoming traffic across servers for availability.
ProxyForwards client requests to servers; can cache and filter traffic.
NASNetwork-attached storage offering file-level access over the network.
SANStorage Area Network providing block-level high-performance storage.
Wireless APProvides Wi‑Fi access for wireless client devices.
Wireless ControllerCentralized management and configuration for multiple APs.
